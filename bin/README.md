# bin — команды проекта

Здесь запускалки для разработки, проверок и деплоя.

> Для владельца/заказчика: что где лежит. Агенту — не always.

## В корне `bin/` (оставить здесь)

Ежедневные и стандартные команды Rails/Node:

| Файл | Зачем |
|------|--------|
| `dev` | Поднять проект локально (Rails + витрина) |
| `server` | Только Rails-сервер |
| `setup` | Первичная настройка |
| `rails` / `rake` / `bundle` | Обычные команды Rails |
| `smoke` / `ci` | Смоук и полный локальный CI |
| `rubocop` / `brakeman` / … | Проверки качества (binstubs gem’ов) |
| `fly_deploy.sh` | Деплой на Fly |
| `kamal` | Деплой через Kamal |
| `docker-entrypoint` | Старт контейнера |
| `vite` | Сборка витрины |

`puma`, `irb`, `jobs` и похожие — **автогенерируемые** binstubs, руками не правим.

## Подпапки (разобрали кучу скриптов)

| Папка | Что внутри |
|-------|------------|
| [`acceptance/`](acceptance/) | Приёмка задач заказчика на Fly (MCP / скрины) — бывшие `b11*`, `b14*`, `b17*`, `b19*`, `b21*` |
| [`prog10/`](prog10/) | Прогон 10 точек / демо-смоук (`prog10_*`) |
| [`fly-tools/`](fly-tools/) | Диагностика Fly: карты/OTP/Firebase/иконки |

Пример запуска после переноса:

```bash
ruby bin/prog10/prog10_fly_smoke.rb
node bin/acceptance/b113_s2a_s2b_rev2_mcp.mjs
ruby bin/fly-tools/usercards_fly_diagnose.rb
```
