# app/jobs

Фоновые задачи (не мешают человеку на экране): колбэки оплаты, пуши и т.п.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`barista/`** — Фоновые задачи панели: экран бариста (точка: заказы, смена)
- **`payments/`** — Фоновые задачи панели: оплата (Т‑Банк, СБП, карты)
- **`shop/`** — Фоновые задачи панели: витрина для гостя (телефон / PWA)

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
