# app/helpers

Мелкие помощники для шаблонов экранов.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`barista/`** — Папка «barista»: часть системы CoffeeOS. Смотри подпапки ниже
- **`platform/`** — Папка «platform»: часть системы CoffeeOS. Смотри подпапки ниже

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
