# app/assets

Картинки и CSS старого стека ассетов.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`images/`** — Папка «images»: часть системы CoffeeOS. Смотри подпапки ниже
- **`stylesheets/`** — Папка «stylesheets»: часть системы CoffeeOS. Смотри подпапки ниже

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
