# app/views

HTML-экраны панелей (бариста, УК, менеджер…) — то, что видит человек в браузере.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`auth/`** — Экраны (HTML) панели: вход в систему (логин)
- **`barista/`** — Экраны (HTML) панели: экран бариста (точка: заказы, смена)
- **`blog/`** — Экраны (HTML) панели: блог / новости
- **`dashboards/`** — Папка «dashboards»: часть системы CoffeeOS. Смотри подпапки ниже
- **`layouts/`** — Общие «рамки» страниц (шапка, меню)
- **`manager/`** — Экраны (HTML) панели: экран управляющего точки
- **`platform/`** — Экраны (HTML) панели: панель управляющей компании (УК)
- **`prep_kitchen/`** — Экраны (HTML) панели: заготовочный цех / склад
- **`pwa/`** — Файлы прогрессивного веб-приложения витрины
- **`shared/`** — Общие куски экранов этой панели
- **`shop/`** — Экраны (HTML) панели: витрина для гостя (телефон / PWA)
- **`test/`** — Папка «test»: часть системы CoffeeOS. Смотри подпапки ниже
- **`tv_board/`** — Экраны (HTML) панели: табло на ТВ в зале

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
