# app/services

Бизнес-логика: создание заказа, оплата, склад, онбординг — без лишнего в контроллерах.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`auth/`** — Сервисы (логика) панели: вход в систему (логин)
- **`barista/`** — Сервисы (логика) панели: экран бариста (точка: заказы, смена)
- **`callbacks/`** — Сервисы (логика) панели: ответы от банка и внешних сервисов
- **`cash_shifts/`** — Кассовые смены
- **`demo/`** — Как показать стенд заказчику / демо на Fly
- **`health/`** — Сервисы (логика) панели: проверка «жива ли система»
- **`inventory/`** — Склад и остатки
- **`payments/`** — Сервисы (логика) панели: оплата (Т‑Банк, СБП, карты)
- **`platform/`** — Сервисы (логика) панели: панель управляющей компании (УК)
- **`prep_kitchen/`** — Сервисы (логика) панели: заготовочный цех / склад
- **`shop/`** — Сервисы (логика) панели: витрина для гостя (телефон / PWA)

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
