# app/components

Переиспользуемые куски UI (кнопки, логотип…).

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`auth/`** — Папка «auth»: часть системы CoffeeOS. Смотри подпапки ниже
- **`ui/`** — Папка «ui»: часть системы CoffeeOS. Смотри подпапки ниже

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
