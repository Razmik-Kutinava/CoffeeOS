# app/frontend

Витрина shop на Svelte: каталог, корзина, оплата, профиль.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`components/`** — Готовые блоки интерфейса витрины
- **`entrypoints/`** — Точки входа сборки фронта
- **`lib/`** — Вспомогательная логика на JS/Ruby рядом с UI
- **`routes/`** — Страницы витрины (каталог, корзина, чекаут…)
- **`styles/`** — Стили (внешний вид) витрины

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
