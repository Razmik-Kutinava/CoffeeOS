# app/controllers

«Двери» сайта: принимают запрос гостя/сотрудника и вызывают нужную логику.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`auth/`** — Контроллеры панели: вход в систему (логин)
- **`barista/`** — Контроллеры панели: экран бариста (точка: заказы, смена)
- **`blog/`** — Контроллеры панели: блог / новости
- **`callbacks/`** — Контроллеры панели: ответы от банка и внешних сервисов
- **`concerns/`** — Общие куски кода, которые подмешивают в несколько мест
- **`health/`** — Контроллеры панели: проверка «жива ли система»
- **`kiosk/`** — Контроллеры панели: киоск самообслуживания
- **`manager/`** — Контроллеры панели: экран управляющего точки
- **`platform/`** — Контроллеры панели: панель управляющей компании (УК)
- **`prep_kitchen/`** — Контроллеры панели: заготовочный цех / склад
- **`shop/`** — Контроллеры панели: витрина для гостя (телефон / PWA)
- **`test/`** — Папка «test»: часть системы CoffeeOS. Смотри подпапки ниже

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
