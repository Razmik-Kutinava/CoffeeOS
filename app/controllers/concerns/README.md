# app/controllers/concerns

Общие куски кода, которые подмешивают в несколько мест.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`barista/`** — Контроллеры панели: экран бариста (точка: заказы, смена)
- **`shop/`** — Контроллеры панели: витрина для гостя (телефон / PWA)

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
