# app/channels

Живые обновления по WebSocket (заказ на табло/у гостя без перезагрузки).

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`application_cable/`** — Папка «application cable»: часть системы CoffeeOS. Смотри подпапки ниже
- **`shop/`** — Папка «shop»: часть системы CoffeeOS. Смотри подпапки ниже

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
