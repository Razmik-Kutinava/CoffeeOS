# app

Сердце приложения: экраны, логика, витрина, модели данных.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`assets/`** — Картинки и CSS старого стека ассетов
- **`channels/`** — Живые обновления по WebSocket (заказ на табло/у гостя без перезагрузки)
- **`components/`** — Переиспользуемые куски UI (кнопки, логотип…)
- **`controllers/`** — «Двери» сайта: принимают запрос гостя/сотрудника и вызывают нужную логику
- **`frontend/`** — Витрина shop на Svelte: каталог, корзина, оплата, профиль
- **`helpers/`** — Мелкие помощники для шаблонов экранов
- **`javascript/`** — Stimulus/JS для панелей Hotwire (не витрина Svelte)
- **`jobs/`** — Фоновые задачи (не мешают человеку на экране): колбэки оплаты, пуши и т.п
- **`mailers/`** — Письма на email
- **`middleware/`** — Прослойки обработки запроса до контроллера
- **`models/`** — Таблицы и сущности БД в коде (заказ, товар, точка, пользователь…)
- **`policies/`** — Кто что может делать (права ролей)
- **`services/`** — Бизнес-логика: создание заказа, оплата, склад, онбординг — без лишнего в контроллерах
- **`views/`** — HTML-экраны панелей (бариста, УК, менеджер…) — то, что видит человек в браузере

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
