# test

Автопроверки: не сломали ли заказ, оплату, права, витрину.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`channels/`** — Папка «channels»: часть системы CoffeeOS. Смотри подпапки ниже
- **`controllers/`** — Папка «controllers»: часть системы CoffeeOS. Смотри подпапки ниже
- **`fixtures/`** — Тестовые данные «как будто из БД»
- **`frontend/`** — Папка «frontend»: часть системы CoffeeOS. Смотри подпапки ниже
- **`helpers/`** — Папка «helpers»: часть системы CoffeeOS. Смотри подпапки ниже
- **`integration/`** — Сквозные проверки сценариев (как живой пользователь)
- **`javascript/`** — Папка «javascript»: часть системы CoffeeOS. Смотри подпапки ниже
- **`jobs/`** — Папка «jobs»: часть системы CoffeeOS. Смотри подпапки ниже
- **`lib/`** — Вспомогательная логика на JS/Ruby рядом с UI
- **`mailers/`** — Папка «mailers»: часть системы CoffeeOS. Смотри подпапки ниже
- **`models/`** — Папка «models»: часть системы CoffeeOS. Смотри подпапки ниже
- **`policies/`** — Папка «policies»: часть системы CoffeeOS. Смотри подпапки ниже
- **`services/`** — Папка «services»: часть системы CoffeeOS. Смотри подпапки ниже
- **`support/`** — Помощники для тестов

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
