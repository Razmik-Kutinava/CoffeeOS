# test/integration

Сквозные проверки сценариев (как живой пользователь).

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`auth/`** — Тесты, связанные с: вход в систему (логин)
- **`barista/`** — Тесты, связанные с: экран бариста (точка: заказы, смена)
- **`demo/`** — Как показать стенд заказчику / демо на Fly
- **`manager/`** — Тесты, связанные с: экран управляющего точки
- **`panels/`** — Папка «panels»: часть системы CoffeeOS. Смотри подпапки ниже
- **`platform/`** — Тесты, связанные с: панель управляющей компании (УК)
- **`shop/`** — Тесты, связанные с: витрина для гостя (телефон / PWA)

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
