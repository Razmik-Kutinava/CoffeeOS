# Core SQL Docs Map

Карта ядра SQL-документов CoffeeOS.  
Порядок чтения: сверху вниз.

1. `01_foundation_rls_core.sql.md` — фундамент: enum, базовые таблицы, RLS/tenant-контур.
2. `02_catalog_menu.sql.md` — каталог и меню: категории, продукты, модификаторы, локальные настройки.
3. `03_barista_tv_board.sql.md` — бариста-табло и TV board: устройства, сессии, причины отмен, настройки экрана.
4. `04_inventory_stop_list.sql.md` — склад ПФ и стоп-лист: ингредиенты, остатки, движения, правила доступности.
5. `05_kiosk_module.sql.md` — киоск: настройки, сессии, корзины, оформление заказа с устройства.
6. `06_shifts_manager.sql.md` — смены и модуль управляющего: состав смены, кассовые операции, контроль статусов.
7. `07_mobile_app_qr_status.sql.md` — мобильное приложение и QR-статус: клиенты, OTP, мобильные сценарии заказа.
8. `08_loyalty_promocodes_push.sql.md` — лояльность, промокоды, push: счета, транзакции, кампании и ограничения.
9. `09_smart_pickup.sql.md` — умная выдача: события выдачи, вызовы, display-настройки, расширения заказов.
10. `10_production_kitchen.sql.md` — заготовочный цех: рецептуры, партии, движение ПФ между тенантами.
11. `11_admin_panel_billing.sql.md` — админка УК и биллинг: расширение tenants, тарифы, подписки, платежная логика.
