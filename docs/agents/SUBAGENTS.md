# Субагенты CoffeeOS (карта)

Канон в правилах: `.cursor/rules/workflow/coffeeos-agent-workflow.mdc` § Skills / субагенты + § Scope / Fly.

> Для владельца. Агенту — не always; смотри always-rules.

## Политика

- **Фича / баг / SBR** → на этапе звать нужный субагент (не всех сразу).
- **Мелочь** → без субагентов; в отчёте `Субагент: нет — мелочь`.
- Лимит **1–2** за шаг. CE/`ce-*` — не по умолчанию.
- **Не** ставить marketplace MCP/gem’ы «для улучшений» без просьбы владельца.

## Hot-path (кратко)

- SPEC: **Не ломать** + **Проверка** обязательны.
- Приёмка: Fly **Point A** (`2fdee1ac-…`); Local ≠ готово заказчику.
- Профиль заказчика: не писать тестовый OTP/телефон.

## Этапы → Cursor Task

| Этап | Субагент | Есть в Cursor |
|------|----------|---------------|
| SPEC / поиск файлов | `explore` | да |
| Длинные тесты / регрессия | `shell` | да |

| CI красный после push | `ci-investigator` | да |
