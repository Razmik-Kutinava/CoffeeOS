# TASK_105 — замер формы оплаты под цифровой клавиатурой

## RED шаг 0 — расчёт по коду (2026-10-11)

**Почему расчёт, а не браузер:** локально до pay-стека нужен подтверждённый телефон (OTP-обход только в `Rails.env.test`), puppeteer в проекте не установлен. Геометрия считается по формулам кода и сверяется со скрином заказчика [01](01_customer_android_pay_form_keyboard_before.png) / [02](02_customer_pay_form_keyboard_from_owner.png). Живая проверка — Point A / Pixel 6 после deploy.

**Модель Android Chrome (`resizes-visual`, без `interactive-widget`):** клавиатура сжимает только visual viewport; layout viewport (CSS `vh`, `position: fixed; bottom: 0`) остаётся 915px. Pixel 6: 412×915, клавиатура ~365px → visual 550px.

| Слой (до, `bb4bdc7f`) | Формула | Без клавиатуры (y, от верха) | С клавиатурой (y) |
|---|---|---|---|
| `CartSheet` pay-peek (карточка товара) | `height = 15% × vvh`, `bottom = (92 − 15)% × vvh` | 74–211 | 409–492 |
| `.pm-sheet--stacked` (форма) | `bottom: 0`, `height = 92vh − 15vh` (layout) | 211–915 | 211–915 (не меняется) |
| Клавиатура + панель Chrome «Мир / Сканировать» | — | — | 550–915 |

**Вывод:**
- С клавиатурой карточка (409–492) оказывается **внутри** формы (211–915) — на скрине она между «СБП» и «Номер карты». Без клавиатуры они стыкуются на 211.
- Низ формы (кнопка «Оплатить») — в зоне 550–915 под клавиатурой; панель автозаполнения Chrome (`autocomplete="cc-number"`) лежит поверх неё — на скрине кнопка срезана.

## После правок (GREEN, расчёт по коду)

`CartSheet` в pay-стеке не рендерится (`{#if showSheet && !payStackActive}`). `.pm-sheet--stacked`: `height = --shop-pay-stack-h` (92% visual viewport), `bottom = --shop-pay-stack-bottom` (низ видимой области), тело `.pm-sheet__body` прокручивается, «Оплатить» (`.pm-sheet__pay`) — под телом, не сжимается.

| Экран | Клавиатура | Шторка оплаты (y) | Видимая область | Прокрутка тела |
|---|---|---|---|---|
| 412×915 | нет | 73–915 (842) | 0–915 | нет (как раньше, карточки сверху нет) |
| 412×915 | 365 | 44–550 (506) | 0–550 | при выбранной «Картой +» — по содержимому |
| 390×844 | 365 | 38–479 (441) | 0–479 | по содержимому |
| 360×640 | 365 | 22–275 (253) | 0–275 | да: шапка + «Оплатить» видны, список/форма листаются внутри |

Во всех случаях низ шторки = верх клавиатуры и панели Chrome «Мир / Сканировать» → «Оплатить» над ними, карточки товара нет.
