## Найдено по ходу GREEN (исправлено в том же шаге)

1. **Poll тянул список назад к открытому чеку.** С открытым чеком список через ≤ 8 с прыгал 397 → 105/247: каждый poll / потеря Cable показывает-прячет строку «Потеряно соединение…» → высота `.oss__list` 103 ↔ 122 → `ResizeObserver` → `fitReceipt` → `scrollTop += scrollDelta`. При `.oss__panel` как контейнере этого не было (у панели фиксированная высота, строка соединения её не меняла). Фикс: список прокручивается к CTA **только при раскрытии** чека (`anchoredOrderId`), refit по `resize` / `ResizeObserver` / `transitionend` пересчитывает только `max-height` чека.
2. Скрин [04](04_after_resize_refit_old_behaviour.png) снят **до** фикса п.1: снятие скриншота шлёт `resize`, и старый refit вернул список к CTA открытого чека.
