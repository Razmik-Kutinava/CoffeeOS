## Три состояния (канон)

1. **expanded** — полные карточки  
2. **peek** — миниатюры + кнопка «+цена»  
3. **hidden (чип)** — только сумма (на макетах отдельного кадра нет — из ТЗ S2)

Скролл каталога вниз: expanded → peek → hidden. Свайп вверх на поп-апе: → expanded (если >1 карточки).
