# Личный кабинет (ЛК) — UI/UX Макеты и Референсы

## Структура макетов

Этот файл содержит UI-макеты для полной реализации личного кабинета в PWA согласно TASK-PERSONAL-CABINET.

### Категории экранов

#### 1. Главный экран ЛК
- **Шапка**: Аватар, имя пользователя, иконка чата/уведомлений
- **PLG-блоки**: Два контейнера для маркетинговых блоков (конфигурируемые)
- **История заказов**: Список недавних заказов с элементами
- **Меню**: Переход к профилю, уведомлениям, о приложении

#### 2. Деталь заказа
- **Шапка**: Дата заказа, номер, статус
- **Товары**: Список позиций с количеством, ценой
- **Сумма**: Итоговая стоимость
- **Действия**: Кнопка «ПОВТОРИТЬ» (без функциональности повтора)

#### 3. Профиль/Настройки
- **Редактирование имени**: Input поле и кнопка сохранить
- **Уведомления**: Тумблер управления
- **Контакты**: Email и телефон с кнопками подтверждения
- **Меню**: Переход к «О нас», bottom sheet «Написать нам», logout

#### 4. Экран «О нас»
- **Информация**: Версия приложения, код сборки
- **Копирование**: Кнопка копирования версии/build-кода
- **Ссылки**: Список юридических/информационных URL из конфигурации
- **Footer**: Копирайт, название организации, email обратной связи

#### 5. Bottom Sheet «Написать нам»
- **Опции**: Email (disabled, скоро), Telegram (активный)
- **Действие Telegram**: Открывает глубокую ссылку на Telegram-бота

## Требования к реализации

- **Стиль**: Темная тема (как в существующем приложении)
- **Компоненты**: Использовать существующие UI-паттерны (bottom sheet, карточки, кнопки)
- **Состояния**: Loading, error, empty, success
- **Accessibility**: aria-labels, semantical HTML, keyboard navigation
- **Responsive**: Mobile-first, адаптация под разные экраны
