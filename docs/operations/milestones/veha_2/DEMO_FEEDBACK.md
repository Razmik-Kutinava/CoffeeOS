# Фидбек заказчика после демо (В2)

**Зачем документ:** правки из прогона **55 сценариев / живого демо В1** не возвращают задачи в чеклист В1 — только очередь **В2** (полировка параллельно онбордингу и оплате).

**Когда наполнять:** по мере поступления от заказчика/Арама. **Сейчас:** пустая очередь, **открыт** — блокер §I до закрытия блокеров здесь.

---

## Правила

1. Одна строка = одна правка (или связанный пакет UI).
2. Статус: `open` → `in_progress` → `done` / `wontfix`.
3. Блокеры онбординга/оплаты — пометка `blocker` + ссылка на PR.
4. Не дублировать техдолг склада/В3 — в `PRACTICES.md` / В3.
