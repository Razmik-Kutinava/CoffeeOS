## Сводка: три направления

| № | Направление | Канал / UI |
|---|-------------|------------|
| **1** | Приём заказа | Витрина (сайт, mobile first) → UI/app → kiosk |
| **2** | Обработка заказа | Табло баристы (Flutter или web mobile first) + панель УК |
| **3** | Обратная связь гостю | Табло + витрина, статусная модель, уведомления, чек на почту |

**Приёмка:** заказчик указывает «+ Приёмка» к отдельным пунктам — сверять с PDF прогонки и [`DEMO_FEEDBACK.md`](DEMO_FEEDBACK.md).

## 1. Приём заказа — витрина (сайт, mobile first)

**Приоритет заказчика:** mobile first.  
**Задачи из приёмки test-1** — добавить экраны, уведомления, регистрацию, юридические блоки → далее UI / app → kiosk.

### 1.1. Настройка каталога (УК)

- Заполнить и настроить **ТТК + фото + модификаторы** через **панель / админку УК**.
- Нужен **путь, как это делать** (туториал).

*Связь с PDF прогонки:* раздел **3.5 «Общее меню сети»**; операционно — [`HANDOFF_UK_MENU_VITRINA.md`](HANDOFF_UK_MENU_VITRINA.md).

### 1.2. Боевые оплаты

- Провести **боевые оплаты** (см. приёмку).

*Связь с PDF прогонки:* **§2.3–2.4** (учебная оплата, двойное «Оплатить»).

### 1.3. Меню: витрина = ядро = табло баристы

- **Почему не отражаются все категории в витрине из ядра** — см. приёмку.
- **Меню:** табло баристы = табло = **витрина**, с **учётом разных цен** по точкам.

*Связь с PDF прогонки:* **§2.1** (меню витрины), **§6.1** (цена на витрине), **§6.4** (экран для зала / TV), **§7.5** (история и меню бариста).

### 1.4. Меню → заказы через табло

- Меню — заказы через табло.

### 1.5. Экран заказа (табло / обработка)

- **UX + функционал:**
  - модификаторы — редактирование;
  - возврат / отказ — **причина**;
  - **оплата на терминал** — SDK шлюза.

### 1.6. UX табло баристы

- Как выглядят **статусы**.
- **Модификаторы**.
- **Отказ** — причины отказа.
- **Возврат** — как выглядит на табло.
- **+ Приёмка**

### 1.7. Уведомления

- **mapi** — ссылка (вариант: как у Dodo): меняется текст при смене **статусной модели**.
- Либо: **popup над нижним баром** со шкалой прогресса.
- **+ Приёмка**

### 1.8. Онбординг

- В онбординге показывать **подсказки**.
- **Порядок** (последовательность шагов).
- **+ Приёмка**

### 1.9. Оплата без экрана банка

- Оплата **без экрана банка**: только **статусы с текстом** + логика по ошибкам (на стороне банка, нашей или иные тех. сложности).
