3. Текущее поведение (факт)

При `Notification.permission === "denied"` существующий flow:
1. показывает сообщение: `Уведомления запрещены в настройках браузера`;
1. предлагает открыть настройки;
1. для Android используется попытка перехода через Android intent;
1. для desktop при отсутствии доступного URL переход не выполняется;
1. после возврата пользователь должен снова видеть существующую статусную модель заказа.

Текущий механизм открытия настроек не гарантирует фактического перехода к настройке разрешения уведомлений текущего сайта во всех браузерах.
