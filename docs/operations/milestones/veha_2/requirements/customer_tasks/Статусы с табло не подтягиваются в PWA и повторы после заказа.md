## Заметки агента

**Симптом:** live-sync статусов POS→PWA только после reload; после завершения заказа «повторы»/история частот не возвращаются без F5.

**Гипотеза root cause (анализ 2026-08-08, код не меняли):**  
1. Обновление статусов в PWA — в основном ActionCable; **нет polling** `/orders/active` (у каталога polling есть). WS на мобильном PWA отваливается → UI замирает до reload.  
2. `refreshFrequentProducts` после terminal в основном по Cable `onTerminal` — пропуск события → пустые повторы до F5.  
3. На `ready`: FE убирает заказ из шторки, BE ещё считает `has_active_order` → пустая шторка + `+0₽` (как на скрине).

**План (SPEC):** polling + `visibilitychange` для active orders; refresh frequent после sync; Cable оставить fast-path.
