## Текст заказчика (дословно)

### Задача

Добавить поле режима работы для точек продаж в админ панели УК

### Проблема

В текущей версии системы отсутствует возможность задать режим работы для точек продаж. Пользователи сайта могут оформить заказ в нерабочее время заведения, что приводит к невозможности выполнения заказа. Отсутствует информирование клиентов о часах работы объекта.

### Решение

**Продуктовые требования:**

- Добавить поле "Режим работы" в форму создания/редактирования точки продаж в админ панели УК
- Режим работы должен учитывать часовой пояс объекта (поле Timezone уже существует в форме)
- Данные о режиме работы должны транслироваться на:
  - Табло баристы (ядро)
  - Сайт продаж
- При посещении сайта и выборе точки продаж вне режима работы отображать информационный баннер "Мы закрыты до [время открытия]"
- Кнопка "Оплатить" должна быть неактивна вне режима работы
- Остальной функционал сайта остается доступным для просмотра

**Технологические требования:**

- Поле режима работы должно поддерживать настройку часов работы по дням недели
- Синхронизация данных режима работы между УК, ядром и сайтом продаж
- Проверка текущего времени с учетом timezone объекта

### User Story

Как владелец точки продаж, я хочу задать режим работы объекта в админ панели, чтобы клиенты при выборе на сайте точки продаж видели актуальную информацию о часах работы и не могли оформить заказ в нерабочее время.

### Use Case

1. Ук создает/редактирует точку продаж в админ панели УК
2. В форме указывает режим работы по дням недели (понедельник-воскресенье) с указанием времени открытия и закрытия
3. Система сохраняет данные режима работы вместе с timezone объекта
4. Данные режима работы передаются на сайт продаж и табло баристы, актуально согласно таймзонам
5. Пользователь заходит на сайт продаж:
   - Если текущее время (с учетом timezone объекта) находится в рамках режима работы — сайт работает в штатном режиме
   - Если текущее время вне режима работы — отображается баннер "Мы закрыты до [время открытия]", кнопка "Оплатить" неактивна

### Ограничения

- Не блокируем весь сайт вне режима работы, только отключаем возможность оплаты
- Не меняем существующую логику работы других модулей точки продаж

### Критерии приёмки

- В форме создания/редактирования точки продаж в админ панели УК добавлено поле "Режим работы" с возможностью указания часов работы для каждого дня недели
- Режим работы сохраняется вместе с данными точки продаж
- Данные режима работы отображаются на сайте продаж
- Вне режима работы на сайте продаж отображается баннер с текстом "Мы закрыты до [время открытия]" с корректным временем следующего открытия и таймзоне
- Вне режима работы кнопка "Оплатить" на сайте продаж неактивна (disabled)
- Остальной функционал сайта продаж доступен для просмотра вне режима работы
- Данные режима работы учитывают timezone объекта \ точки продаж при выборе пользователем для заказа при определении текущего статуса (открыто/закрыто)
- Табло баристы (ядро) получает и отображает заказы согласно режима работы
