## Текст заказчика (дословно)

### ЗАДАЧА 2: Клиентская часть (CoffeeOS)

**Название задачи:**

Отображать адрес точки продаж и реализовать выбор точки в правом верхнем углу приложения CoffeeOS

**Описание:**

**Проблема:**

В приложении CoffeeOS в левом верхнем углу отображается название бренда «CoffeeOS» (см. скриншот 1). Пользователи не видят, к какой конкретной точке продаж они подключены, что создаёт неудобства при работе с несколькими кофейнями. Отсутствует возможность быстрого переключения между точками прожарки.

**Решение:**

**Продуктовые требования:**

- В правом верхнем углу приложения вместо «CoffeeOS» отображать адрес текущей точки продаж в формате: «Город, Адрес»
- Добавить функциональность выбора/смены точки прожарки через выпадающий список с адресами
- Данные получать из панели УК через API: карточка точки → Входы и URL → поля «Город» + «Адрес»

**Технологические требования:**

- Интеграция с API панели УК для получения данных о точках продаж
- Отображение полей: city + address из карточки точки
- Реализация механизма переключения между точками с сохранением контекста пользователя
- Кеширование данных для работы при временном отсутствии соединения

**User Story:**

Как сотрудник кофейни, я хочу видеть адрес точки продаж в интерфейсе приложения и иметь возможность переключаться между точками прожарки, чтобы понимать, с какой точкой я работаю, и оперативно менять точку при необходимости.

**Use Case:**

1. Пользователь открывает сайт / pwa CoffeeOS
2. В левом верхнем углу автоматически отображается адрес текущей точки (Город, Адрес), полученный из панели УК
3. При клике на адрес открывается выпадающий список доступных точек прожарки с адресами
4. Пользователь выбирает другую точку из списка
5. Приложение переключается на выбранную точку, адрес в шапке обновляется
6. Данные о выбранной точке сохраняются в сессии, подставляется адрес последний точки продажи

**Corner cases:**

- Если поле «Город» или «Адрес» не заполнено — отображать доступные данные, показывать заглушку «Адрес не указан»
- Если у пользователя доступ только к одной точке — показывать адрес без возможности переключения (иконка не кликабельна)
- При отсутствии соединения с сервером — показывать последнее закешированное значение адреса
- Если API возвращает ошибку — показывать адрес из локального хранилища

**Ограничения, чего не делаем:**

- Не меняем расположение элемента — остаётся в левом верхнем углу
- Не меняем общий дизайн и стилистику шапки приложения
- Не добавляем новые поля в карточку точки в панели УК (это сделано в задаче 1)

**Критерии приёмки:**

- В левом верхнем углу приложения (вместо «CoffeeOS») отображается адрес точки в формате «Город, Адрес» (см. скриншот 1 — область слева от кнопки «Установить»)
- Адрес корректно подгружается из панели УК (раздел Точки → Карточка → Входы и URL → поля «Город» + «Адрес»)
- При клике на адрес открывается список доступных точек прожарки с адресами
- При выборе другой точки из списка приложение переключается на неё, адрес в шапке обновляется
- Если поля «Город» или «Адрес» не заполнены, отображается корректная заглушка «Адрес не указан»
- При отсутствии интернета отображается последнее закешированное значение адреса
