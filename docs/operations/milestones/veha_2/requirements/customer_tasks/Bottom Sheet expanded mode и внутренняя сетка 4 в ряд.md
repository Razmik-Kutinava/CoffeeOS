## Текст заказчика (канон — без сокращений)

# Bottom Sheet: Expanded Mode Layout Fix & Internal Grid Refactor

## Бизнес-контекст
В режиме expanded bottom sheet перекрывает каталог некорректно — виден второй ряд товаров, что нарушает визуальную иерархию и UX. Внутри сетки товары отображаются в неоптимальном формате: нет фиксированной сетки 4 в ряд, отсутствует внутренний скролл при переполнении. Необходимо привести layout к UX-паттернам, зафиксированным в cursor rules.

## Глобальные ограничения
- Не менять структуру данных товаров и корзину (state management).
- Не трогать логику добавления/удаления товаров (кнопки +/−/Удалить).
- Не менять header шторки (адрес, профиль, время работы).
- Не менять кнопку "+184₽" (итоговая сумма).
- Размеры карточек и отступы брать строго из cursor rules (UX паттерны).

## Сценарии реализации (Use Cases в Gherkin)

### Шаг 1 — Expanded mode: высота шторки до первого ряда каталога

- [ ] Given: Bottom sheet в collapsed состоянии, каталог отображает категории "Черный" и "Фильр-кофе" с двумя рядами товаров в каждой
- When: Пользователь тянет шторку вверх (swipe up) или тапает на handle
- Then: Шторка переходит в expanded mode, её верхний край совпадает с началом второго ряда товаров категории "Фильр-кофе" (виден только первый ряд каждой категории каталога)

- [ ] Given: Bottom sheet в expanded mode
- When: Пользователь тянет шторку вниз (swipe down)
- Then: Шторка возвращается в collapsed mode, каталог полностью видим

### Шаг 2 — Внутренняя сетка товаров: 4 в ряд

- [ ] Given: Сетка каталога на главной, в категории 4 товара
- When: Каталог отрисован
- Then: Товары отображаются в сетке 4 в ряд (горизонтально), карточки имеют размеры согласно cursor rules UX паттернам

- [ ] Given: Сетка каталога на главной, в категории 5+ товаров
- When: Каталог отрисован
- Then: Первые 4 товара видны в первом ряду, остальные доступны через вертикальный скролл внутри области товаров

- [ ] Given: Сетка каталога на главной, в категории 1–3 товара
- When: Каталог отрисован
- Then: Товары отображаются в одном ряду (1–3 карточки), скролл не активируется

### Шаг 3 — Размеры карточек и отступы

- [ ] Given: Сетка каталога на главной
- When: Отрисовка карточек товаров
- Then: Ширина карточки, высота, padding, gap между карточками соответствуют значениям из cursor rules (UX паттерны для mobile grid)

## Экстремальные сценарии (Error & Edge States)

- **1 товар в списке**: карточка занимает 1/4 ширины ряда (не растягивается на всю ширину), сетка сохраняется.
- **Длинное название товара**: текст обрезается с ellipsis после N строк (согласно cursor rules), не ломает высоту карточки.
- **Нет фото товара**: placeholder "Нет фото" отображается в том же размере карточки, без деформации сетки.
- **Быстрый swipe up/down**: анимация не прерывается, высота корректно фиксируется на snap point.
- **Ресайз окна (tablet/desktop)**: сетка пересчитывается, но логика "4 в ряд + скролл" сохраняется.

## Критерии авто-выхода (Exit Criteria)

1. Код проходит unit/интеграционные тесты под эти сценарии.
2. Проверка типов TypeScript (tsc) и линтер проходят без ошибок сборки.
3. Визуальный тест: в expanded mode виден ровно 1 ряд товаров каталога (второй ряд полностью скрыт под шторкой).
