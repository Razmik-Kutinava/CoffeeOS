## Бизнес-цель

Добавить в личный кабинет PWA рабочий канал связи с поддержкой через Telegram-бота из двух существующих точек входа — иконки чата в шапке главного экрана ЛК и кнопки «Написать нам» на экране профиля. Реализовать только Telegram-канал, не затрагивая email-канал и не создавая встроенный чат.

## 3. Сценарии и Чек-лист (Gherkin)

### Subtask 1: Подключить Telegram-ссылку поддержки через конфигурацию
- **Given:** в приложении отсутствует или требуется обновить ссылка поддержки
- **When:** компонент Telegram-канала получает URL
- **Then:** используется конфигурационное значение `https://t.me/code_black_support_bot`, а URL не хардкодится непосредственно в разметке bottom sheet

### Subtask 2: Реализовать открытие шторки из иконки-чата
- **Given:** пользователь находится на главном экране ЛК
- **When:** пользователь нажимает иконку-чата в шапке
- **Then:** открывается bottom sheet с вариантами Email и Telegram

### Subtask 3: Реализовать Telegram-вариант в шторке главного экрана
- **Given:** bottom sheet открыт
- **When:** пользователь выбирает Telegram
- **Then:** открывается `https://t.me/code_black_support_bot` без передачи пользовательского или заказного контекста

### Subtask 4: Сохранить email-вариант без реализации email-логики
- **Given:** bottom sheet отображает варианты связи
- **When:** пользователь выбирает Email
- **Then:** email-канал не выполняет новую бизнес-логику; допускается disabled/скрытое состояние либо визуальный пункт без обработчика

### Subtask 5: Реализовать открытие шторки из профиля
- **Given:** пользователь находится на экране профиля
- **When:** пользователь нажимает «Написать нам»
- **Then:** открывается bottom sheet с теми же вариантами Email и Telegram

### Subtask 6: Реализовать Telegram-вариант в шторке профиля
- **Given:** bottom sheet профиля открыт
- **When:** пользователь выбирает Telegram
- **Then:** открывается `https://t.me/code_black_support_bot` без передачи пользовательского или заказного контекста

### Subtask 7: Исключить встроенный Telegram Web App
- **Given:** пользователь выбирает Telegram
- **When:** выполняется переход
- **Then:** приложение использует обычный deep link и не создает iframe, Telegram Web App или встроенный чат внутри PWA

### Subtask 8: Проверить мобильный сценарий deep link
- **Given:** PWA открыта в мобильном браузере/как установленное PWA
- **When:** пользователь выбирает Telegram
- **Then:** при наличии установленного Telegram система передает ссылку нативному клиенту Telegram; при отсутствии клиента пользователь может продолжить через веб-версию Telegram

### Subtask 9: Проверить desktop-сценарий deep link
- **Given:** PWA открыта в desktop-браузере
- **When:** пользователь выбирает Telegram
- **Then:** Telegram открывается через web-версию в новой вкладке/окне согласно поведению браузера

### Subtask 10: Проверить отсутствие контекстных параметров
- **Given:** пользователь авторизован и у него доступны имя, телефон и история заказов
- **When:** пользователь открывает Telegram
- **Then:** URL не содержит user_id, имени, телефона, order_id, CustomerKey или других пользовательских параметров

### Subtask 11: Проверить единообразие двух точек входа
- **Given:** Telegram доступен из шапки и профиля
- **When:** пользователь использует любой из двух сценариев
- **Then:** используется один и тот же URL поддержки и одинаковая логика перехода

### Subtask 12: Выполнить регрессионную проверку ЛК
- **Given:** Telegram-канал реализован
- **When:** выполняется проверка личного кабинета
- **Then:** открытие профиля, история заказов, экран деталей заказа, logout и существующие элементы ЛК продолжают работать без изменений

## 6. Связка: Telegram Bot Support

- **Точки входа:** PWA ЛК — иконка-чата в шапке главного экрана и кнопка «Написать нам» на экране профиля. Оба сценария открывают `https://t.me/code_black_support_bot`.
- **Identity Mapping:** отсутствует. user_id, имя, телефон, order_id, CustomerKey и иные внутренние идентификаторы пользователя в Telegram не передаются.
- **Handling Errors:** приложение не реализует собственный API-вызов к Telegram. При невозможности открыть нативный клиент используется стандартное поведение deep link/веб-версии Telegram, зависящее от ОС и браузера.
- **Security:** пользовательские и заказные данные не включаются в deep link. Ссылка хранится в конфигурации приложения. Секреты и Telegram Bot API credentials в PWA не используются.
- **Bot:** @code_black_support_bot
- **Bot Description:** «Привет, бот-помощник для цифровой кофейни CODE: BLACK»
- **Start/Welcome Message:** настраивается заказчиком в BotFather и не является частью реализации PWA
