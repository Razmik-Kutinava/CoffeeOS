## Описание

### Проблема:
Текущая форма оформления заказа содержит избыточные поля и навигацию, неоптимальный способ связи с клиентом (телефон вместо email). Требуется упростить процесс оформления заказа и адаптировать его под текущие бизнес-процессы.

### Решение:

**Продуктовые требования:**
- Упростить форму оформления заказа для пользователей
- Заменить способ связи с клиентом с телефона на email
- Реализовать верификацию email через код подтверждения
- Убрать нефункциональные элементы интерфейса

**Технологические требования:**
- Интеграция с email-шлюзом для отправки кодов подтверждения
- Валидация email адреса
- Маскировка поля ввода email

**User Story:**
Как пользователь, я хочу оформить заказ, указав свой email для получения подтверждения, чтобы быстро завершить покупку без ввода телефона и лишних полей.

**Use Case:**
1. Пользователь переходит на экран оформления заказа
2. Вводит имя в поле "Имя"
3. Вводит корректный email в поле "Email"
4. Нажимает "Получить код подтверждения"
5. Вводит код из письма
6. Выбирает способ оплаты
7. Нажимает "Оплатить"

### Изменения:

1. **Поле "Телефон" заменить на "Email":**
   - Реализовать отправку кода подтверждения на email
   - Добавить кнопку "Отправить код"
   - Добавить поле ввода кода подтверждения

2. **Убрать поле "Комментарий"**

3. **Убрать отображение наличия товаров**

4. **Кнопка "СБП":**
   - Сделать неактивной (disabled)
   - При нажатии показывать сообщение "Будет позже"

5. **Чекбокс "Выдача в машину"** - убрать 
6. **Убрать хлебные крошки:** "Корзина → Оформление → Оплата → История"

### Ограничения:
- Не меняем общую структуру страницы оформления заказа
- Не меняем логику работы кнопки "Оплатить"
- Не меняем остальные элементы навигации

### Критерии приёмки:

1. Поле "Телефон" заменено на поле "Email" с валидацией формата email
2. Реализована отправка кода подтверждения на email
3. Поле "Комментарий" отсутствует на странице
4. Информация о наличии товаров не отображается
5. Кнопка "СБП" неактивна, при клике отображается tooltip/сообщение "Будет позже"
6. ~~Чекбокс "Выдача в машину" отображается и функционирует~~ **Устарело:** по разделу «Изменения» чекбокс убран; приёмка — отсутствие поля на checkout
7. Хлебные крошки "Корзина → Оформление → Оплата → История" скрыты
8. Форма проходит валидацию перед оплатой
9. Код подтверждения отправляется на указанный email
10. Без ввода кода подтверждения заказ не оформляется

>
> **Фактический результат:**  
> Заказ не отменяется, кнопка «Отмена заказа» не реагирует на нажатие (или заказ продолжает создаваться)
>
> **Ожидаемый результат:**  
> При нажатии кнопки «Отмена заказа» заказ должен отменяться, пользователь должен возвращаться на предыдущий экран (в корзину или каталог)
>
