1. Карта интеграций — затронуто / нет

- Затронуто: отображение профиля в шапке витрины PWA.
- Не затронуто: API профиля, авторизация, сессия, оформление заказа, оплата, чеки, push-уведомления и маршрутизация.
- Не менять контракт получения профиля и формат идентификатора в данных.

2. Карта компонентов — компонент, общий файл, новый компонент

- Основной компонент: "app/frontend/components/Header.svelte".
- Общий файл с другими задачами: да.
- Связанные сценарии: B1.11 (часы работы), B1.13-S1 (профиль), B1.14 (адрес), #67 (Telegram WebView), #69 (удаление иконки чата поддержки).
- Новый компонент: нет.
- Граница изменений: разрешено менять только отображение подписи профиля в шапке и необходимые для этого тесты. Существующие адрес, часы работы и другие независимые элементы шапки должны остаться без изменений.

3. Текущее поведение — факт

По результатам read-only аудита:

- "app/frontend/components/Header.svelte:22-25" формирует подпись «Профиль › [сокращённый ID]».
- "app/frontend/components/Header.svelte:146-147" содержит текстовую подпись профиля для обычной ширины экрана.
- "app/frontend/lib/shopProfileHeader.js:2-7" сокращает длинный идентификатор.
- На узком экране предусмотрено отдельное отображение иконки и сокращённого идентификатора.
- Тесты не проверяют точное соответствие отображаемой подписи новому требованию.

Эти сведения описывают поведение до выполнения задачи и не являются разрешением менять вспомогательную логику идентификатора.

4. Scope

Разрешено

- Заменить отображение профиля в правом верхнем углу витрины на точный текст «Профиль ID».
- Убрать из этого элемента отображаемый UUID или его сокращение.
- Убрать из этого элемента стрелку "›", иконку профиля, троеточие и любые дополнительные подписи или бейджи.
- Обеспечить одинаковый результат на обычной и узкой ширине экрана.
- Добавить или скорректировать тесты, проверяющие точный текст и отсутствие дополнительных элементов профиля.
- Проверить существующие защитные тесты B1.13-S1 и обновить только те проверки, которые требуют прежнего формата подписи.

Запрещено

- Менять API профиля, формат UUID, получение или хранение идентификатора.
- Менять поведение профиля внутри личного кабинета.
- Возвращать или удалять иконку поддержки в рамках этой задачи.
- Менять Telegram, email, адрес, часы работы, маршруты, авторизацию, сессию, оплату, чеки и push-уведомления.
- Менять поведение других задач, использующих "Header.svelte".
- Изменять "COMPONENT_MAP.md" до успешного Review и прохождения тестов.

5. Gherkin

- [ ] Subtask 1 — точная подпись профиля

  Given: пользователь видит шапку витрины PWA.
  When: шапка отображается на обычной ширине экрана.
  Then: в правом верхнем углу отображается точный текст «Профиль ID». Сам UUID и его сокращённая форма не отображаются. Стрелка "›", иконка профиля, троеточие и дополнительные элементы внутри подписи профиля отсутствуют.

- [ ] Subtask 2 — узкий экран

  Given: пользователь открывает витрину на узком экране, в том числе шириной менее 360 CSS-пикселей.
  When: отображается шапка витрины.
  Then: в правом верхнем углу по-прежнему отображается только текст «Профиль ID». Сокращённый идентификатор, отдельный бейдж с ID и иконка профиля не отображаются.

- [ ] Subtask 3 — регрессионная защита соседних элементов

  Given: шапка витрины содержит адрес и часы работы, предусмотренные другими задачами.
  When: подпись профиля изменена.
  Then: адрес, часы работы и прочие элементы шапки, не относящиеся к подписи профиля, продолжают работать по прежним правилам.

- [ ] Subtask 4 — защитные тесты прежнего поведения

  Given: существующие тесты B1.13-S1 проверяют прежний формат подписи или сокращение идентификатора.
  When: новая реализация проверяется тестами.
  Then: проверки, требующие старую видимую подпись, заменены проверками нового требования. Защитные тесты других функций и компонентов не ослаблены и не удалены без обоснования.
