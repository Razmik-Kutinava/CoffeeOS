# Карточка товара: отображение набранных позиций и функциональность в режиме peek

## Проблема
Пользователи PWA CoffeeOS при переходе в карточку товара с уже набранными позициями не видят свои выбранные позиции. Это приводит к непониманию, что уже добавлено в заказ. В режиме peek утрачивается возможность горизонтального скролла и редактирования заказа (-1/+1).

## Решение

### Продуктовые требования
- Пользователь видит свои набранные позиции в карточке товара
- Сохраняется возможность редактирования количества в режиме peek
- Сохраняется горизонтальный скролл в режиме peek
- Есть кнопка с надписью “добавить к заказу” см скриншот

### User Story
Как пользователь CoffeeOS, я хочу видеть свои набранные позиции в карточке товара и иметь возможность их редактировать в режиме peek, чтобы контролировать состав заказа без дополнительных переходов.

## Use Case
1. Пользователь набирает позиции в корзине
2. Переходит в карточку товара, где уже есть набранные позиции
3. В карточке товара отображается индикатор наличия позиций в заказе
4. При открытии режима peek пользователь видит свои позиции
5. Пользователь может изменить количество (-1/+1) в режиме peek
6. Пользователь может скроллить позиции горизонтально в режиме peek

## Критерии приёмки

### Сценарий 1: Отображение набранных позиций в карточке товара
**Given:** Пользователь добавил товар "Фильтр-кофе Бразилия" в корзину (1 или более штук)  
**When:** Пользователь переходит в карточку этого товара  
**Then:** В карточке товара отображается индикатор количества добавленных позиций (например, "уже в заказе: 1")

- [ ] **Тест-критерий:** В DOM присутствует элемент с количеством товара в корзине
- [ ] **Тест-критерий:** При изменении количества в корзине индикатор обновляется реактивно

### Сценарий 2: Режим peek — отображение набранных позиций
**Given:** Пользователь добавил несколько позиций в корзину  
**When:** Пользователь открывает корзину в режиме peek  
**Then:** Отображаются все набранные позиции с возможностью просмотра

- [ ] **Тест-критерий:** В режиме peek отображается список всех позиций из корзины
- [ ] **Тест-критерий:** Каждая позиция содержит название, количество и цену

### Сценарий 3: Режим peek — редактирование количества
**Given:** Пользователь открыл корзину в режиме peek и видит набранные позиции  
**When:** Пользователь нажимает кнопки -1 или +1 у позиции  
**Then:** Количество позиции изменяется, общая сумма пересчитывается

- [ ] **Тест-критерий:** Кнопки -1 и +1 активны и обрабатывают клики
- [ ] **Тест-критерий:** При нажатии +1 количество увеличивается на 1
- [ ] **Тест-критерий:** При нажатии -1 количество уменьшается на 1
- [ ] **Тест-критерий:** Общая сумма корзины пересчитывается после изменения

### Сценарий 4: Режим peek — горизонтальный скролл
**Given:** В корзине в режиме peek несколько позиций  
**When:** Пользователь делает свайп влево/вправо  
**Then:** Список позиций скроллится горизонтально

- [ ] **Тест-критерий:** Контейнер с позициями имеет горизонтальный скролл
- [ ] **Тест-критерий:** Свайп жесты обрабатываются корректно
- [ ] **Тест-критерий:** Все позиции доступны для просмотра при скролле

## Экстремальные сценарии

### Сценарий 5: Пустая корзина в режиме peek
**Given:** Корзина пуста  
**When:** Пользователь открывает режим peek  
**Then:** Отображается сообщение о пустой корзине или режим peek не открывается

- [ ] **Тест-критерий:** Обработчик корректно реагирует на пустую корзину

### Сценарий 6: Ошибка при изменении количества
**Given:** Пользователь в режиме peek нажимает +1  
**When:** API возвращает ошибку  
**Then:** Количество откатывается, показывается сообщение об ошибке

- [ ] **Тест-критерий:** При ошибке API состояние откатывается к предыдущему
- [ ] **Тест-критерий:** Пользователь видит сообщение об ошибке

### Сценарий 7: Товар закончился
**Given:** Товар есть в корзине  
**When:** Товар закончился на складе  
**Then:** В карточке товара и в peek режиме показывается индикатор "нет в наличии"

- [ ] **Тест-критерий:** Отображается индикатор отсутствия товара
- [ ] **Тест-критерий:** Кнопки редактирования заблокированы
