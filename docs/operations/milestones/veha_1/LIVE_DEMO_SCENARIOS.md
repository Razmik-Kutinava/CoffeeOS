## 12. Веха 2 — что **не** показывать как готовое (старт разработки)

| Тема | В1 (демо сейчас) | В2 (разработка) |
|------|------------------|-----------------|
| Оплата | Mock `SHOP_SIMULATE_PAYMENT` | Платёжный шлюз, callbacks |
| Смена | Shop/киоск **без** смены; barista **со** сменой | Единые правила сети; offline POS |
| Киоск | Нет UI | Flutter, API как shop |
| Offline | Нет | Drift/Hive, sync engine |
| Склад | v0.1, минус OK, не полный журнал | Движения на каждое списание → Event Sourcing (В3) |
| Outbox / CB | Нет | Solid Queue, Circuit Breaker |
