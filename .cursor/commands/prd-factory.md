# /prd-factory (устарело)

Режим **PRD Factory** и файл `.cursor/rules/prd-factory-agent.mdc` **сняты**.

Действуй по актуальным правилам:

1. Прочитай **`.cursorrules`** (главный операционный контракт: `ISSUES`, `SESSION_STATE`, коммиты, продуктовые md, деструктив).
2. При необходимости — **`docs/agents/AGENTS.md`**.
3. Баг/ошибка → **сразу** `docs/operations/ISSUES.md`, довести до «решено» с описанием фикса.
4. Прогресс сессии → **`docs/operations/SESSION_STATE.md`** батчами (2–3+ шага, смена задачи, важный поворот или каждые 3–4 коммита).

Не ссылайся на удалённый `prd-factory-agent.mdc`.
