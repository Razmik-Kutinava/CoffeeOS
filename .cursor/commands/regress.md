# /regress — отдельная регрессия зоны (не в дефолтной цепочке)

CoffeeOS. Канон зоны: `coffeeos-dev-gates.mdc` + **«Проверка»** в todo.  
**Дефолт:** после GREEN → сразу `/review` (local зона — шаг 1 PHASE 3). Отдельный `/regress` **не** звать «на всякий».

## Когда нужен отдельно (иначе — нет)

| Случай | Зачем |
|--------|--------|
| После GREEN **не** идёшь в `/review` (пауза, другая задача) | Зона не сломана, пока ждёшь |
| Пачка патчей **до** одного `/review` | Промежуточная проверка зоны |
| Хотфикс / чинка после FAIL **без** полного PHASE 3 | Быстрый local без Entire/push |
| Явная просьба владельца | — |

**Не дублировать:** если `/regress` только что PASS и код с тех пор не менялся — в `/review` шаг 1: `Local: reuse /regress PASS` (не гонять снова).

## Сделай
1. Зона (shop / оплата / platform / barista / RLS / …).
2. Команды из **«Проверка»** в todo; пусто — таблица зон `coffeeos-dev-gates`.
3. Длинный прогон → Task **`shell`**.
4. Legacy shop ~24 fail — **не** гейт.
5. Отчёт: команда + runs/failures. FAIL → ISSUES или фикс.
6. Hot-path: напомни Fly MCP Point A для «готово заказчику».
7. Шапка SESSION_STATE (зона + PASS/FAIL). Ops-коммит если менял файлы.
