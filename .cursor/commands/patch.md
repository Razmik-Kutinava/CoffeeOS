# /patch — кривая задача (патч / доп.задача)

Канон: `docs/operations/dev/TASK_PATCH.md` · правило `coffeeos-task-patch.mdc`.  
**Не** заменяет SBR / commit-ops / intake. **Не** на мелочь и не на обычную новую фичу.

## Когда

После Review / приёмки: поведение или ответ **кривой**; дыра в ТЗ; вернуть осознанно убранное.  
Мелочь / «просто дальше по чеклисту» → стоп: «/patch не нужен».

## Сделай

1. Прочитай `docs/operations/dev/TASK_PATCH.md` (этот запуск — один раз).  
2. Шаг 1–3 канона: карта → аудит если нужен (без правок кода) → **ПАТЧ | ДОП.ЗАДАЧА | ПЕРЕПИСАТЬ**.  
3. Шаг 4: документ по шаблону (патч = секция в TASK; EXT = новый файл).  
4. Шаг 5: секция в `docs/operations/session/todo.md` (не плодить `todo-*.md`).  
5. **Не** трогай `COMPONENT_MAP.md` на Spec — только после Review (шаг 6 канона / БЛОК 4).  
6. Коммит + ops по `coffeeos-commit-ops`. Отчёт: тип правки · пути документов · `Next:`.

## Токены

Не тащи SBR/unlazy/весь CHANGELOG без нужды. Аудит — только файлы зоны задачи.
