# .cursor/rules

Файлы правил агента (workflow = процесс, project = код).

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`project/`** — Правила «как писать код» (RLS, сервисы, UI, тесты)
- **`workflow/`** — Правила «как вести задачу» (коммит, SBR, тесты, куда класть файлы)

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
