# config

Настройки приложения (среда, секреты, инициализация).

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`certs/`** — Сертификаты (если нужны для интеграций)
- **`environments/`** — Настройки development / test / production
- **`initializers/`** — Код, который запускается при старте Rails
- **`locales/`** — Тексты на разных языках
- **`secrets/`** — Секреты (ключи). Сами ключи в git не кладём

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
