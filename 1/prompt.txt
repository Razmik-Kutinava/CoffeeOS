### Канон CoffeeOS / SBR

1. **SPEC** — `todo.md`: этап N, файлы, **Не ломать**, **Проверка**; шапка SESSION/HANDOFF; ссылка на ТЗ + макеты.  
2. **RED** — падающие тесты UI/controller → `test: B2.2 stage-N … [RED]`.  
3. **GREEN** — layout/логика → regress → `feat: B2.2 stage-N … [GREEN]`.  
4. **REVIEW** — bugbot + security-review + Entire + push CI. Deploy — только апрув владельца.

Правила: `coffeeos-http` (namespace barista), `coffeeos-services` (создание заказа/оплата не в толстом контроллере), `coffeeos-ui` (Hotwire/ERB), `coffeeos-core` (tenant/смена).  
Субагент на SPEC: `explore` если пути размазаны; на BUILD — по необходимости `shell` для тестов.

**Стек barista:** Rails + Hotwire/Turbo (+ Stimulus при необходимости). **Не** переносить Svelte shop CartSheet на barista.
