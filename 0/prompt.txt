АУДИТ (БЕЗ ИЗМЕНЕНИЙ КОДА) — повторный запрос email после оплаты

Контекст

Проблема: в PWA после успешной оплаты пользователю предлагается указать email для отправки чека. После следующей оплаты PWA снова запрашивает email, хотя по исходной задаче сохранённый email должен предзаполняться для повторного заказа.

Связанные документы:

"docs/operations/milestones/veha_2/requirements/customer_tasks/TASK-[Email-сбор после оплаты].md"
задача «Доработка бэкенда — передача email покупателя в Receipt для фискальных чеков»
"docs/operations/session/COMPONENT_MAP.md"
"docs/operations/INTEGRATIONS.md"

Правила: только чтение кода/git log/blame, без изменений кода, без исправлений и без рекомендаций до завершения аудита. Каждый факт фиксировать как "файл:строка". Если факт невозможно установить — явно написать «не установлено».

Для каждого перехода указать:

Шаг → Факт → файл:строка

Нужно установить:

1. где success screen получает начальное значение email;
2. откуда frontend получает сохранённый email;

9. сбрасывает ли frontend email при каждом открытии success screen.
