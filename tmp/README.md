# tmp

Временные файлы. Можно чистить. В git не храним.

> Для владельца и заказчика: что лежит в этой папке простыми словами. Агенту читать только если нужно понять зону — **не always**.

## Что внутри

- **`pids/`** — Служебные файлы процесса (pid/сокеты). Не для людей
- **`sockets/`** — Служебные файлы процесса (pid/сокеты). Не для людей
- **`storage/`** — Папка «storage»: часть системы CoffeeOS. Смотри подпапки ниже

## Зачем это нам

Чтобы быстро понимать структуру CoffeeOS без чтения кода.
